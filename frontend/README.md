
# Frontend

This folder contains the frontend web application for the Online Bookstore project.

## Purpose

The frontend provides the user interface for:
- viewing books,
- viewing ratings and reviews,
- interacting with backend services.

## Expected features

- Home page
- Book list page
- Book details section
- Reviews and ratings display
- Loading and error states

## Suggested stack

The frontend member may use:
- React
- Vite
- HTML/CSS/JavaScript
- Nginx for serving the built application

## Responsibilities

- Build the web UI
- Connect the frontend to backend APIs
- Handle loading and error states
- Ensure the frontend can run locally and later be containerized

## Notes

Keep the frontend simple and focused on demonstrating microservice integration.
