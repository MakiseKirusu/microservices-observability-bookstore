
# Istio Configuration

This folder contains Istio configuration files for the Online Bookstore project.

## Expected contents

- Gateway
- VirtualService
- DestinationRule
- PeerAuthentication
- Traffic policies
- Retry, timeout, and circuit breaker configuration

## Purpose

These files are used to demonstrate service mesh features such as:
- mTLS
- ingress routing
- canary deployment
- timeout
- retry
- circuit breaker

## Notes

All Istio resources should be documented clearly so the demo flow is easy to explain.
