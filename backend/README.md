# Backend

This folder contains all backend microservices used in the Online Bookstore project.

## Services

- `catalog-service`
- `review-service`
- `rating-service`

## Purpose

The backend is responsible for:
- storing and serving book data,
- storing and serving reviews,
- storing and serving ratings,
- supporting service-to-service communication for the project demo.

## Notes

Each microservice should be kept independent and easy to deploy as a container.
