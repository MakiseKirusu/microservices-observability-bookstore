# Demo Checklist

- Frontend can load successfully
- Catalog service is reachable
- Review service is reachable
- Rating service is reachable
- Services are deployed in Kubernetes
- Istio is installed
- Gateway and routing are working
- mTLS is enabled
- Canary routing is demonstrated
- Timeout or retry is demonstrated
- Metrics are visible in Grafana
- Traces are visible in Jaeger
- Service graph is visible in Kiali
- Logs are available
- Slides and screenshots are prepared
